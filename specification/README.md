1. Review and complete `.project.yml`.
2. Verify that the configured paths exist:
   - Requirements: `requirements`
   - Epics: `requirements/epics`
   - Plans: `plans`
   - Tasks: `tasks`
3. Read [projecttrace-guide/UsageGuide.md](projecttrace-guide/UsageGuide.md) for the installed operational workflow.
4. Validate the destination as described in
   [Validation and Checklist](projecttrace-guide/harness-reference.md#validation-and-checklist).

## Workflow

```text
specify -> analyze -> plan -> approve -> create_tasks -> implement -> test -> trace
```

Start any requirements work with `@analyst-requirements`; it invokes the
source, issue, and E2E traceability agents and the code audit as needed and is
the only agent that edits epics, the domain model, the glossary, and the
traceability matrix.

The approvals configured in `.project.yml` must be satisfied before creating tasks
or starting implementation. The installation does not create fictional requirements,
epics, tasks, decisions, or sources.

## Commands

- Requirements index: `python scripts/idx.py build [--check]`, `python scripts/idx.py stats`, or `python scripts/idx.py find <ID>`.
- Installed version: `python scripts/idx.py version [--kit <local-kit-path>]` (the kit path enables a Git commit comparison).
- Consolidate epics with Python, only when `modules.consolidate_epics` and
  `features.consolidate_epics.enabled` are `true`:
  `python scripts/consolidate-epics.py [--output <file>] [--check]`.
- Validation: the validator is not installed in this repository; run it from a
  ProjectTraceKit checkout with
  `python <kit>/scripts/validate-template.py --root <destination> --requirements`.

By default the Python consolidator generates `requirements/epics/epics-consolidated.md`.
It is a generated file: do not edit it by hand. It is versioned in this
repository and committed in the same commit as the epic changes, together with
the index regenerated by `idx.py build`; `@analyst-requirements` regenerates
both after editing epics. If the epics did not change, the consolidator leaves
the file untouched. `--check` writes nothing and fails when the index or the
consolidated document is missing or stale. On Linux and macOS use `python3`
if `python` is not available.
